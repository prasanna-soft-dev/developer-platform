# Product Overview

## Project Name

Developer Productivity Platform

> Working name. The final product name may change.

---

## 1. Vision

The goal of this project is to build a single platform that helps developers
learn, plan, track, and collaborate throughout their technical journey.

The platform will initially begin as a DSA tracker and gradually evolve into
a broader developer productivity and learning platform.

The long-term goal is to bring multiple developer workflows into one place:

- Learning
- Problem solving
- Task management
- Roadmap planning
- Goal tracking
- Suggestions
- Collaboration
- Progress tracking

---

## 2. Current Product

### Version

v0.1.0

### Current Module

DSA Tracker

The first version focuses on tracking coding problems and learning progress.

---

## 3. Current Features

### Problem Management

Users can:

- Create problems
- View problems
- Edit problems
- Delete problems
- Add problem links
- Assign companies
- Assign topics
- Assign difficulty
- Track solving status
- Add notes

### Company Management

Users can:

- Create companies
- View companies
- Associate problems with companies

### Topic Management

Users can:

- Create topics
- View topics
- Associate problems with topics

### Dashboard

The dashboard currently provides:

- Total problems
- Solved problems
- Problems yet to solve
- Solving percentage

### Filtering

The interface provides filtering options for:

- Company
- Topic
- Difficulty
- Status

### Search

Problems can be searched from the dashboard.

---

# 4. Current Scope

The current version is intentionally simple.

There is currently no:

- User authentication
- User registration
- Authorization
- User-specific data isolation
- Todo management
- Roadmap management
- Collaboration
- Notifications
- Real-time communication
- AI recommendation system

These are planned for future versions.
